Dev Tools

A collection of simple, browser-based developer utilities.

Case Converter

Convert text between uppercase, lowercase, title case, and more.

Word Counter

Count words, characters, sentences, and paragraphs.

Find & Replace

Search and replace text with optional regex support.

Join Lines

Join lines of text together with a delimiter of your choice.

Split Text

Split text into separate lines by a delimiter.

JSON Compare

Compare two JSON values and see the differences.

JWT Decoder

Decode and inspect JSON Web Token header, payload, and signature.

Time Converter

Convert times between UTC, EST, PST, and other timezones.

UUID Generator

Generate single or batch UUID v4 values.

Text Diff

Compare two blocks of text side-by-side with highlighted differences.
